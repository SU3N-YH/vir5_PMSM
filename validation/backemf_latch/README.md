# BackEMF CORDIC 锁存（2026-11-12）

Update 2026-11-16: the schedule and one-stage multiplier description below
are historical. Current RTL uses a two-stage DSP, the dedicated 180 MHz
CORDIC, and publication at count 1. See [the current repair report](../backemf180/README.md).

`BackEMF.v` 保持原端口、Q 格式、单个一级流水线乘法器，以及每 18 拍统一更新
五相输出的调度。顶层 `u_back_EMF` 的时钟连接仍为原来的 50 MHz；本次准备
模块内部逻辑供后续切换至 180 MHz 使用。

## 寄存器与调度

| 计数 | 动作 |
| --- | --- |
| 15 | 空闲时采样同一个外部角度，分别寄存 counts×160 和 counts×20 |
| 16 | 寄存两部分之和，得到 counts×180 的 Q16.16 角度 |
| 17 | 寄存五相偏移后的角度，隔开角度换算与 CORDIC 象限归一化路径 |
| 18 | 仅在完整准备好输入且不忙时，同时启动五个 CORDIC |
| 任意拍 | busy 且五路 oDone 同时有效时，统一锁存取负并饱和后的正弦结果 |
| 2 | 将上一拍前已完成的结果复制到整帧快照，供 4/7/10/13/16 拍加载乘法器 |

计算期间角度流水寄存器保持不变。完成批次与整帧快照使用两个寄存器组，
即使计算完成落在某个相的乘法期间，也只会在下一次第 2 拍采用新结果。
完成与第 2 拍重合时，本帧使用上一批结果。初始化和计算中复位均清零所有锁存。
五个相同核心共用时钟、复位和启动，要求五路完成信号同步。

原核心的启动周期仍为 36 拍，180 MHz 下角度批次更新率为 5 MHz，输出发布
频率为 10 MHz。角度现在采样于启动前 3 拍，速度/磁链仍在每帧第 1 拍采样。
首次计算完成之前正弦快照为零。外部角度连续变化时，计算采用被采样的角度；
最终保持的角度会在后续空闲批次被采样。

## 验证

- `powershell -File tools/run_backemf5_sim.ps1`：真实 CORDIC 和真实结构乘法器
  的 403 组数值回归通过，STM32 读回最大误差为 1 个码值。
- `powershell -File tools/run_backemf_latch_sim.ps1`：真实核心分别在 50 MHz 和
  约 180 MHz 的 RTL 仿真中通过；覆盖每拍变化的角度、正负速度/磁链、
  静止零角、最终角度保持、计算期间复位，以及五相每拍输出的精确计分板。
- 同一脚本另用测试专用 CORDIC 模型引入 7..53 拍可变计算延迟，完成锁存
  覆盖全部 18 个计数位置（done_slots=0007fffe），五相整帧一致性检查通过。
  此模型只参与独立仿真，不加入主工程。

日志位于 `real180/test.log`、`real50/test.log` 和 `variable180/test.log`。
单模块 ISE XST 综合文件与报告位于 `synth/`。
XST 综合通过，0 个错误、162 个警告；警告主要涉及常量/等价寄存器裁剪、
原 atan 常量表以及 STM32 输出截断。2026-11-13 改用 `MUL18x18_bEMF`
后重新综合，模块使用 1 个 DSP48A1，估算最小周期为 8.862 ns
（112.838 MHz），所列关键路径为 E 相角度寄存器到 CORDIC 归一化角度寄存器。
该数值不是布局布线后的结果，也未证明 180 MHz 可用。

RTL 仿真不包含器件延迟；这些锁存隔开外围组合路径并消除对固定完成拍数的
依赖，不代表 CORDIC 内部移位/加减迭代、乘法器或整机已通过 180 MHz 时序。
正式升频仍需设置有效的 5.556 ns 时钟约束，布局布线并检查建立/保持时间以及
50 MHz FMC 到新时钟域的数据传递。
