# 五相中性点平均值：division5 / Q19（2026-11-13）

`add5ov5.v` 提供三组独立五相平均值，输入和输出均为有符号 S35_Q17。
使用用户已生成的 `ipcore_dir/division5`，不重新生成或更改其配置：
有符号 18×35→53 位、一级流水线、2 个 DSP48A1。

## 定点数与溢出处理

- 系数为 `104858 / 2^19`，即 `round(2^19/5)`，相对增益误差约 `+3.815e-6`。
  系数 104858 可放入 18 位有符号输入端口；Q19 指缩放因子，不是端口宽度。
- 五个 35 位输入先分别符号扩展再求和，和保留为 38 位，覆盖完整输入范围。
- 为复用 35 位 IP 操作数端口，使用精确分解：
  `sum = 8 * signed(sum[37:3]) + unsigned(sum[2:0])`。
  高 35 位进入 IP，低 3 位用三个常数移位加法项补偿，不推导额外 DSP。
  对负数也成立，不丢弃低位，也不将 38 位和直接截断为 35 位。
- 完整乘积保留 56 位，加 `2^18` 后右移 19 位，按最近整数舍入（半整数朝正方向）。
  Q19 倒数存在近似误差，不再宣称输出等于精确除以 5。
- Q19 系数略偏大，满量程附近可能将平均值推出 S35 范围，因此在输出处饱和，避免回绕。
  未饱和时，倒数近似误差最多为 65536 个输出原始编码 LSB，舍入再增加至多 0.5 LSB。
  实际电压的近似误差与输入平均值成比例，例如 100 V 时约为 0.0003815 V。

## 工程与清理

活动工程 `vir5_PMSM.xise` 通过 `division5.xco` 登记乘法器，与 `Inductor` 的 IP
登记方式一致，可在 ISE 中直接打开 CoreGen 修改配置；不单独登记其 `.v` 或 `.ngc`。
`Inductor_DE` 使用的 `mul_inductor_2` 同样改为 `.xco` 登记。
编译源清单和命令行仿真仍使用 CoreGen 生成的 `.v` 模型；`.ngc` 是生成后的实现文件，
这些配套文件保留在磁盘中。旧的宽位乘法器 IP 文件和专用 CoreGen/仿真/综合缓存
已从工程目录删除；`original/` 中只保留早先的源文件历史，不保留旧 IP 实现。

顶层原先被注释的中性点实例仍处于注释状态；本次仅更新平均值模块及其工程依赖。
历史 `main.sch`、`main.vf`、`main.prj` 不是当前活动工程入口。

## 验证

- `powershell -File tools/run_neutral5_sim.ps1`：真实 `division5` 结构 IP，约 180 MHz
  仿真时钟，4499 次输出更新检查通过。覆盖完整量程、近量程、D/E 相单独输入、
  正负低 3 位余数、随机输入、Q19 舍入、饱和、输出保持、运行中复位和中性点流水线。
  参考模型使用直接 64 位乘法，独立于 RTL 高低位分解。日志：`sim/test.log`。
- ISE XST：0 错误，11 个常数寄存器优化警告。外部 RTL 预估周期 4.636 ns；
  此报告不包含黑盒 IP 内部时序。报告：`division5_build/division5.syr`。
- NGDBUILD：实际链接 `division5.ngc`，0 错误、0 警告。
  报告：`division5_build/add5ov5.bld`。

  详见报告。实际资源为 **2 个 DSP48A1**，从原来的 9 个减少 7 个。
  报告：`division5_build/add5ov5_map.mrp`。
- 工程引用唯一性、旧 IP 文件清理和活动 `case (Time_cnt)` 调度检查通过。
